# Guillan Loyola — Astro portfolio

Responsive static Astro site, using the three original Carrd project images.

## Run

```sh
npm install
npm run dev
```

Build with `npm run build`. Deploy the generated `dist/` directory to any static host.

Edit project details in `src/pages/index.astro`. The original page has placeholder contact details, so the contact button links back to the current Carrd page. Replace it with your real email or enquiry link before using it as your main portfolio.
